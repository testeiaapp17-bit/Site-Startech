# Site StarTech Brasil

Site da StarTech Brasil: aluguel de Starlink por diária em Cuiabá e região, planos mensais e venda para empresas e órgãos públicos de todo o Brasil.

- `index.html`: site completo em um arquivo (logo embutido, sem dependências externas).
- `logo.png`: logo com fundo transparente.

Para alterar o número do WhatsApp, edite a constante `WHATSAPP` no final do `index.html`.
Os valores das diárias ficam na constante `TIERS`, logo abaixo.

Publicação: funciona direto no GitHub Pages, Vercel, Netlify ou qualquer hospedagem estática.
